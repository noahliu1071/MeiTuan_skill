# 方法与反模式

## 可复用方法

### 证据四层法
**何时使用**：费率、功能、结算、准入和收益判断。  
**做法**：当前合同/后台实测 ＞ 有日期正式文件 ＞ 培训/OCR ＞ 第三方说法；每个结论写来源、日期、适用对象和待验证项。  
**代价**：速度稍慢，但能避免把历史材料变成当前承诺。

### 门店上线七步法
核对名称/品类/电话/地址 → 营业状态 → 标签与人员 → 入口图 → 头图 → 相册/视频 → 消费者视角复核。

### 多业态三图头图分工
**何时使用**：一家门店的主营品类之外还有实际经营的其他服务或商品，且店铺首屏并排展示多张头图。

**做法**：主营服务 → 空间体验 → 补充业态；选图前先给每张图分配任务，发现重复画面就换图。生成素材逐项核对实店设施；文字放在留白处，单图与并排缩略图都要看清。

**边界**：图中出现的商品不自动成为团购权益；历史图片规格以当前后台为准。

### 收单展业黄金五步链路
筛选商户 → 邀约建联 → 价值传递 → 硬件售卖/交付 → 运营回访。用合格商机、首笔真实交易和持续使用评价结果。

### 八步进件验收链
行业准入 → 主体资质 → 门店信息 → 联系人 → 结算实名 → 费率/协议 → 设备与支付认证 → 真实交易验收。

### 商品三层组品
引流款降低首次门槛，主推款表达核心价值，利润款改善客单/毛利；每层写明成本、限制和承接能力。

### 流量漏斗诊断
曝光 → 点击/进店 → 咨询/下单 → 核销 → 评价/复购。定位最先出现的断点，不只看曝光。

### 商户激活闭环
开通 → 首笔真实交易 → 员工会用 → 老板会查账 → 异常有人处理 → 7/14/30天回访 → 持续真实交易。

### 收益核算边界
只在内部授权数据中核算合同收入、结算、代理付款和公司支出；公开资料不记录采购类信息。

### 唯一事实链
商户台账 → 交易明细 → 平台结算 → 代理付款 → 公司成本。数据岗维护唯一底表，其他岗位提交更正。

### 问题驱动内容法
一个真实问题 → 一个场景 → 三步排查/操作 → 适用条件 → 下一步动作；按合格咨询到持续交易复盘。

## 反模式

- 把收款、点餐、收款单、钱多多Plus、POS和会员能力写成一个万能产品。
- 把培训示例、规划、试点或旧政策写成当前统一规则。
- 把开通数、设备数、代理数或流水当成利润或持续使用。
- 用平台账单比例直接承诺代理收益或公司净留存。
- 宣传自动好评、必然曝光、全行业开通、固定到账、永久低费率或躺赚。
- 装机后不培训、不验收、不回访，只追求新增数量。
- 把待出账当到账、缺失当零、累计快照逐日相加或跨通道重复交易。
- 未经授权公开商户、员工、后台、聊天或交易数据。
- 连续多张头图重复展示同类设施，或为了美观保留生成模型虚构的设施。
- 在复杂设备前放低对比度标题，只检查大图而忽略首屏缩略图。
- 一次改变多个变量，无法判断动作效果。
