# 方法与反模式

## 可复用方法

1. **门店上线七步法**：核对名称/品类/电话/地址 → 营业时间 → 标签与服务人员 → 入口图 → 头图 → 相册/视频 → 消费者视角复核。
2. **商品三层组品**：定义引流目标，设计主推价值，补充利润或组合服务；每层写明成本、限制、适用人群和承接能力。
3. **流量漏斗诊断**：曝光 → 点击/进店 → 咨询/下单 → 核销 → 评价/复购。使用相同周期和口径，定位最先出现的断点。
4. **投放四步**：目标用户和需求 → 预算与日期/时段 → 创意 → 出价与关键词；先小范围测试，记录花费和下游结果。
5. **评价闭环**：消费前管理期待，消费中保证一致性并处理问题，消费后回访；差评按触点、责任人和整改事项复盘。

## 反模式

- 把培训课件的示例分值、时段、预算比例或效果描述当作平台统一规则。
- 只追求曝光、排名或好评数量，不看咨询、下单、核销、成本和真实履约。
- 页面承诺与线下服务、时长、数量、节假日限制不一致。
- 用刷量、虚假购买、代写评价、强制好评、利益换指定评价或诱导删差评改善指标。
- 一次同时修改预算、时段、素材、关键词和套餐，导致无法判断原因。
- 没有客户数据、行业、城市和成本约束就承诺排名、销量、ROI或收益。
