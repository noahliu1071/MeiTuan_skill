# ch08 美团赚赚产品定位与证据边界

## 核心思想

把美团赚赚理解为“收款底座＋适用的经营能力”，不要把所有美团商家工具打包成一个万能产品。核心链路是：顾客真实支付 → 商家获得播报和交易记录 → 在符合条件时出现评价、收藏或买单销量等经营入口 → 商家继续服务和复盘。

## 产品分层矩阵

1. **轻量收款设备**：码牌、音箱，重点是收款、播报、查账和基础交付。
2. **收银硬件**：扫码王、智能POS，设备能力和适用场景须按型号说明。
3. **经营产品**：扫码点餐、收款单、钱多多Plus、会员或连锁能力，是不同产品线、套餐或阶段能力。
4. **支付通道**：美团支付相关通道与第三方收单通道不是同一主体；功能、费率和结算不能互相套用。

## 功能证据门

每个卖点按四级证据判断：当前合同/后台实测 ＞ 有日期的正式文件 ＞ 培训课件/OCR ＞ 第三方文章或销售话术。公开页面能说明产品方向，不能替代某门店的准入、费率、结算和展示结果。产品规划、试点城市和“后续上线”不能写成当前标配。

回答产品问题时使用五列卡片：产品/设备名称、已确认能力、适用对象、证据日期、待验证事项。支付后评价不等于自动好评；买单销量不等于外卖或团购销量；设备免费、永久低费率和流量提升都需要单独证据。

## 反模式

- 只看“美团”品牌就把外卖、团购、点餐、会员和收款能力全部合并。
- 把历史App名称、旧版本或其他地区页面当作当前功能。
- 用产品宣传页证明商家一定审核通过或一定获得经营效果。

来源类型：产品公开说明、产品手册、业务知识地图及全库证据评估；当前能力仍以实际后台和合同为准。
