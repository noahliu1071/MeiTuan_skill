# ch14 自媒体内容与业务获客

## 问题驱动内容法

一条内容只解决一个真实问题：开通后为什么没用、老板如何查记录、员工怎么用设备、常见故障怎么处理、什么商家需要先核实条件。内容先给核查路径和动作，再介绍产品；不要把广告口号当知识。

## 内容业务漏斗

播放、点赞是触达信号，业务指标是：合格咨询 → 预约/完成演示 → 进件 → 首笔真实交易 → 观察期内持续使用。每条内容记录内容ID、发布时间、目标人群、线索来源和后续阶段，按同批线索计算转化。

## 证据与授权

操作路径、费率、到账、设备、准入和营销能力发布前核对当前资料。公开可识别商家、员工、聊天、交易或后台前取得明确授权并约定素材范围、平台和脱敏方式；无授权时使用通用演示，不把虚构故事包装成真实案例。

## 可复制内容结构

钩子指出一个具体损失或困惑 → 展示真实场景 → 给3步排查/操作 → 说明适用条件 → 给下一步咨询或自查动作。标题避免“保证、永久、全行业、自动涨好评、躺赚”等绝对承诺。

设备画面需要遮挡真实二维码时，用清晰的非功能性演示码补足外观并标注“演示”，不要嵌入真实收款信息；柜台收款码和桌台点餐码要区分。这是用户的视觉偏好，不是平台规则。

来源类型：自媒体内容策略、已制作脚本和广告复盘资料。
