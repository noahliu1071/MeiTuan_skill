# ch03 自然流量与推广通

先看曝光、访问和意向转化，判断是没被看见、被看见但没人点，还是进店后没有咨询/下单。自然流量排查基础信息、商品/团单完整度、经营评分待办、评价/服务质量、关键词与真实项目的匹配。关键词可按常规词、季节词、热搜词组织，必须符合真实服务，避免堆砌和误导。

推广通测试顺序：目标用户与需求 → 预算和日期/时段 → 创意 → 基础/关键词出价。先小范围测试，记录曝光、点击/进店、咨询或下单、核销、花费和获客成本。曝光不足检查预算、时段、覆盖词和出价；曝光有而点击弱看图片、标题和展示；点击有而下单弱看套餐、价格、详情、评价和服务承接。

提高出价不等于保证排名、订单或 ROI。课件中的预算上调比例、预热时长、时段和竞价示例需当前后台核验。
