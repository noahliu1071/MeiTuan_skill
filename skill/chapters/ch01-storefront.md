# ch01 门店基础信息与页面装修

新店上线或页面点击弱时，先核对名称、品类、电话、地址、商圈、营业时间、标签和适用的服务人员信息，再处理图片。课件把装修分为入口图、头图、相册/视频：入口图负责列表页第一印象，头图负责详情页定位和优势，相册/视频让用户理解真实环境、设施、项目和效果。

执行顺序：基础信息 → 营业状态 → 标签/人员 → 入口图 → 头图 → 相册/视频 → 消费者视角复核。素材应真实、清晰、主体突出、有授权；促销素材在活动结束后及时更新。用户进入页面后应快速理解门店是谁、适合谁、服务什么、价格和限制是什么、怎么预约。

头图拼接式展示是用户指定的视觉偏好，可作构图参考，不是平台规格。后台路径、名称格式、营业时间限制、商圈距离和图片规格均可能变化，执行前要查看当前后台。
