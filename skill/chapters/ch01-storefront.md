# ch01 门店基础信息与页面装修

新店上线或页面点击弱时，先核对名称、品类、电话、地址、商圈、营业时间、标签和适用的服务人员信息，再处理图片。课件把装修分为入口图、头图、相册/视频：入口图负责列表页第一印象，头图负责详情页定位和优势，相册/视频让用户理解真实环境、设施、项目和效果。

执行顺序：基础信息 → 营业状态 → 标签/人员 → 入口图 → 头图 → 相册/视频 → 消费者视角复核。素材应真实、清晰、主体突出、有授权；促销素材在活动结束后及时更新。用户进入页面后应快速理解门店是谁、适合谁、服务什么、价格和限制是什么、怎么预约。

## 环境设施图片制作流程（实战沉淀）

环境/设施图用于建立真实感和空间预期，不等同于团购权益图。建议按“整体空间 → 休息/等候区 → 饮品与基础设施 → 灯光与氛围 → 入口识别”分工制作，优先使用门店最新实拍，按需要做轻度裁切、透视校正、补光、白平衡和杂物整理。

每张图生成或处理后必须完成：

1. 以真实照片为底稿，先确认主体、空间比例和设施确实存在；
2. 明确该图只展示什么，避免一张图同时承担环境、价格和权益说明；
3. 公开展示前检查敏感元素，德州酒馆/智力竞技类门店不展示牌面、筹码、现金、下注、博彩文字或明显赌桌标线；必要时使用同色系素面覆盖、裁切或中性化墙面标识；
4. 生成后人工复核是否出现虚构家具、窗户、吧台、人物、豪华装修或错误文字；不合格就重做，不把模型幻觉当实景；
5. 同时保留高清母版和当前后台要求的上传版（例如项目实战使用的1125×843 4:3候选版），规格以当前后台提示为准；
6. 在客户案例过程记录中写明原始素材、处理内容、真实性边界、合规边界、交付文件和用途。

本项目实战已验证四类环境图：整体空间、沙发休息区、饮品柜与饮品区、灯光与整体氛围。灯光氛围图可做轻度视觉整理，但发布前必须与门店当前实景核对；环境图不应暗示团购包含照片中的具体饮品或设施权益。

头图拼接式展示是用户指定的视觉偏好，可作构图参考，不是平台规格。后台路径、名称格式、营业时间限制、商圈距离和图片规格均可能变化，执行前要查看当前后台。
