# ch05 经营评分与数据复盘

经营评分可作为待办清单，帮助检查基础信息、商品丰富度、服务质量和交易表现。不同业态的权重、牌级门槛和任务会变化，不能把电脑维修、按摩/足疗等课件示例套到所有门店。

先定义问题和统计周期，再看曝光/访问、点击/进店、咨询/下单、核销、退款、评价、复购和成本。把指标转成动作：信息缺失补信息，点击弱改素材和首屏，咨询弱改响应和详情，核销弱查履约，评价弱查服务和期待。

复盘记录目标、周期、数据口径、改动项、预算/时段/素材/关键词、结果和外部因素。优先同周期对比，样本小、节假日或库存变化明显时不作强因果结论。

做收款业务经营复盘时，开通数、设备出货、代理数、有效交易额、平台应计分润、实际到账和公司净留存必须分表记录。数据最低链路是：全量商户台账 → 真实交易明细 → 平台结算单 → 代理应付/实付 → 公司成本。缺失数据留空或标“未取得”，不能记成零；待出账、待确认不能记成现金到账。

推荐按半月复盘，保留日粒度原始资料。看有效流水、笔数、去重有交易商户、首笔真实交易、D7/D30持续使用、集中度、骤降门店和销售漏斗。同一来源、同一进入时间的商机才可计算转化率；未成熟批次不报留存结论。

来源：原项目经营评分资料；美团赚赚经营部署、账单复盘和四岗协作资料。内部阈值是管理建议，不是平台标准。
