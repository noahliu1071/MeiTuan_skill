# ch09 支付进件、通道与结算交付

## 标准进件链路

使用“八步验收链”：行业准入 → 主体与资质 → 门店照片和基本信息 → 联系人 → 结算账户与实名 → 费率/协议确认 → 设备绑定与支付认证 → 真实交易验收。不要把“提交申请”写成“已开通”，也不要承诺固定审核时长。

企业、个体户和个人资质的结算账户、授权函和经营场所证明要求可能不同。门头图、店内图、主体名称、地址和经营范围应互相一致；OCR自动填充后仍要人工核对。支付认证、设备绑定和营销能力可能是不同状态，必须逐项确认。

## 通道与结算五问

解释任何通道前先回答：谁提供收单服务、商家实际费率是什么、交易何时清算、钱结算到哪里、异常/退款/冻结如何处理。再补充行业、地区、银行卡、活动期限、额度和设备兼容条件。D+1、T+1、逐笔到账、钱包到账、银行卡到账和实时到账不是同义词。

不同通道可以有独立的进件、认证、设备和结算规则；阶段资料中出现的“可切换”“次日生效”“暂不支持”都必须按当前后台复核。同一交易不能被两个通道重复统计。

## 交付验收

完成进件后，用真实小额交易核对商户名称、支付成功、播报、交易查询、结算去向、退款入口和权限；再检查评价/收藏等经营能力是否实际开通。保存协议版本、后台状态、设备SN、操作人、验收时间和异常工单。

## 变更控制

收款人、结算卡、门店资质、门店信息、联系人、费率、超管账号和注销不是同一种变更；部分核心主体字段可能必须注销后重开。执行前查看当前入口、权限和在审任务，避免并发变更造成状态冲突。

来源类型：进件操作手册、经营宝手册、通道答疑和银行卡变更资料；路径与条件可能更新。
