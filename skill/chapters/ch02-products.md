# ch02 团购创建与爆款组品

把商品设计成“引流—促销—利润”组合，而不是只做一个低价套餐。引流款承担首次转化，主推款承担核心价值表达，利润款或组合服务改善客单和毛利。每款都要与实际服务能力、库存、时长、预约和节假日限制一致。

设计流程：明确用户和场景 → 盘点成本、容量、人员和可用时段 → 设计标题、卖点、价格、适用人群和限制 → 组合服务 → 检查详情、预约、核销和线下履约 → 看曝光、点击、购买、核销、退款、评价和毛利。

低价团单带来大量咨询但无法预约，先修承接；购买多但评价差，先修服务和期待；有曝光无点击，先查标题、首图、价格和信任信息。培训课件中的套餐价格、案例行业和活动入口只是示例。
