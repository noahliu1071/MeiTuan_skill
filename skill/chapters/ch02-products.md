# ch02 团购创建与爆款组品

把商品设计成“引流—促销—利润”组合，而不是只做一个低价套餐。引流款承担首次转化，主推款承担核心价值表达，利润款或组合服务改善客单和毛利。每款都要与实际服务能力、库存、时长、预约和节假日限制一致。

设计流程：明确用户和场景 → 盘点成本、容量、人员和可用时段 → 设计标题、卖点、价格、适用人群和限制 → 组合服务 → 检查详情、预约、核销和线下履约 → 看曝光、点击、购买、核销、退款、评价和毛利。

低价团单带来大量咨询但无法预约，先修承接；购买多但评价差，先修服务和期待；有曝光无点击，先查标题、首图、价格和信任信息。培训课件中的套餐价格、案例行业和活动入口只是示例。

## 已过审的到店团购落地流程（2026-11-05 实战沉淀）

适用于有真实门店、需要从0搭建首批到店团购的场景；具体字段仍以当前商家后台为准。

### 1. 先定商品角色和四项首批结构

- 新店首轮可规划至少4款角色明确的商品：低门槛体验款、女性/特定人群权益款、储值促销款、较高额度储值款。
- 不要先堆套餐数量；每款都要写清目标、权益边界、履约容量和后续承接关系。
- 引流款先验证点击、购买、核销和评价，再决定是否加大曝光或调整价格。

### 2. 价格锚点先保证真实，再谈折扣感

- 团购价必须低于门市价，但门市价应是门店愿意实际执行的日常价格。
- 不用98、128等缺乏依据的虚高原价制造大折扣；可用自然的日常价形成可信锚点。
- 价格判断同时看服务时长、座位/产能、直接成本、平台费用、预约压力和后续升单空间。

### 3. 详情页用五张图回答五个问题

在支持最多5张16:9详情图的到店商品中，可按以下顺序组织：

1. 套餐主视觉：用户第一眼看懂体验调性。
2. 真实环境全景：证明场景真实、门店空间可到店。
3. 服务/座位细节：展示具体使用位置和整洁度。
4. 体验氛围：展示真实成年顾客的交流、体验或操作状态。
5. 休息与配套环境，或在规则确认后制作权益说明：补足配套和使用疑问。

图片不得把环境道具伪装成套餐权益；饮品、设备和装饰只在实际包含或明确说明时才能作为权益表达。

### 4. 三段式团购详情填写法

- 服务项目：只写消费者真正买到的核心项目、数量、单位、时长和门店售价；一个核心体验不拆成多个虚假小项。
- 图文详情：用真实门店图和体验图回答“环境怎样、坐哪里、怎么体验”；不要承诺尚未确认的全天可用、全部项目或免费饮品。
- 补充信息：用短句列出适用人数、体验时长、套餐包含、不包含项目和现场安排方式。

### 5. 购买须知默认检查框架

以固定座位、需要排座的2小时体验款为例，可优先考虑：审核通过即售、自动延期、不限正常售卖渠道、购买后90天有效、周末节假日可履约时全部日期可用、提前预约、设定实际使用人数、不与其他优惠同享、设置合理的单人购买上限。预约提前量和使用时段必须按门店真实营业时间、接待能力、迟到/超时规则确认，90天不是平台统一规定。

### 6. 合规与发布前验收

- 页面、团购标题、图文和线下履约必须描述同一项真实服务；敏感经营内容不能靠修图掩盖实际服务或规避平台审核。
- 对涉及桌面智力竞技/策略体验的门店，公开素材不得出现现金输赢、筹码兑付、下注、抽水、赌博组织、牌面花色、赌桌标线、收益暗示或容易误读的敏感文字。
- 发布前按顾客路径检查：能否搜到 → 是否愿意点击 → 买到什么/多久/怎么用是否清楚 → 预约和使用限制是否可执行 → 员工口径是否一致。

以上是本次大庆门店“单人2小时桌游体验”已通过审核的流程总结；其中价格、有效期、预约提前量和购买上限是经营建议，不是所有门店的固定规则。
