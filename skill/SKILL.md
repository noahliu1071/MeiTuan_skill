## 证据分层：先确定能说到哪一步

1. **当前合同/后台实测**：决定实际费率、资格、通道、结算、功能和状态；记录门店、版本与日期。
2. **有日期正式文件/平台公开说明**：可说明文件当时的规则或产品方向；先检查适用期和对象。
3. **培训课件、OCR与案例**：用于提取方法和操作线索；数字、小字、效果及当前入口须复核。
4. **用户经营事实**：用户的业务范围、门店数据、团队能力和计划；不等于平台授权或行业规则。
5. **推断/待验证**：写依据、假设、验证动作和成功指标，不伪装成事实。

当费用、处罚、功能入口、活动资格、通道、到账、代理收益或评分机制可能变化时，答复前核对当前官方来源/后台；无法核实时写明来源日期和不确定性。

## 通用诊断顺序

门店问题按“定位与人群 → 页面 → 商品/团购 → 流量漏斗 → 咨询/履约/评价 → 数据复盘”定位最先断点。收款业务按“产品线 → 行业/主体准入 → 通道与结算 → 进件/设备 → 首笔真实交易 → 持续使用 → 账单与利润”定位。风险或合规有硬伤时先修，再扩量。

## 核心框架

- **增长飞轮**：可信页面/产品 → 合适商品与流量 → 真实履约/交易 → 评价与持续使用 → 数据复盘 → 下一轮优化。
- **产品分层矩阵**：码牌/音箱、扫码王/POS、扫码点餐、收款单、钱多多Plus及支付通道分别核对；品牌相同不代表能力通用。
- **证据四层法**：当前合同/后台 ＞ 正式文件 ＞ 培训/OCR ＞ 第三方话术。每个结论带日期、对象和限制。
- **引流—主推—利润组品**：商品承担不同角色，但都必须匹配成本、容量、限制和实际履约。
- **团购素材完整性门**：每款团购按“1:1货架图 → 16:9详情页图 → 服务项目/图文详情/补充信息 → 价格与购买须知 → 发布检查”顺序完成，货架图不能因详情页已制作而省略。
- **多业态门店头图**：首屏多图按“主营服务 → 空间体验 → 补充业态”分工，逐张检查真实设施、画面重复、文字对比度和并排效果；具体执行见 [ch01](chapters/ch01-storefront.md)。
- **流量漏斗**：曝光 → 点击/进店 → 咨询/下单 → 核销 → 评价/复购；先修最早断点。
- **收单展业黄金五步链路**：筛选商户 → 邀约建联 → 价值传递 → 硬件售卖/交付 → 运营回访。
- **八步进件验收链**：准入 → 资质 → 门店 → 联系人 → 结算实名 → 费率协议 → 设备/认证 → 真实交易验收。
- **商户激活闭环**：开通不等于激活；装机后还要员工会用、老板会查账、异常有人处理，并验证持续真实交易。
- **收益核算框架**：只使用经过授权的结算、收入和支出数据核算经营结果；公开版本不记录设备采购信息。
- **唯一事实链**：商户台账 → 交易明细 → 平台结算 → 代理付款 → 公司成本。缺失不记零，应计不当到账。
- **问题驱动内容法**：一条内容解决一个真实问题，用合格咨询、演示、进件、首笔交易和持续使用衡量，而不是只看播放。
- **单变量复盘**：一次优先改变一个关键变量，记录周期、口径、素材、预算、时段和结果。
