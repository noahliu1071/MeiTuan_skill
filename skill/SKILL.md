# 美团运营专家

这是一个项目级知识 skill。使用前先阅读项目根目录的 `AGENTS.md`、`README.md` 和 `知识库/索引.md`。本 skill 的来源是 `原始资料/` 下 16 份用户提供并整理的 Markdown 资料；原始截图仍在相应目录中。

## 先做证据分层

回答任何具体问题时，把内容标成以下四类：

1. **平台规则**：用户提供的规则摘录或已核验的官方页面。涉及费用、处罚、功能入口、资格、尺寸、流量机制时，先核验当前官方后台或规则中心。
2. **培训方法**：商户培训课件给出的经营建议。可作为行动假设，不作为统一规则、效果保证或排名承诺。
3. **门店事实**：客户提供的页面、图片、价格、数据、流程和限制。没有资料就不要补写。
4. **推断/待验证**：由资料推导出的判断。写明依据、验证动作和成功指标。

## 通用诊断顺序

面对一家门店，依次检查：定位与目标人群；基础信息和页面；商品/团购；曝光到核销的漏斗；评价、咨询与履约；最后做低成本修复、单变量测试和复盘。

## 核心框架

- **营销正循环/门店增长飞轮**：基础信息与页面承接 → 商品与团购 → 流量获取 → 到店履约 → 评价与复购 → 数据复盘，再反哺页面、商品和流量。
- **流量二分法**：自然流量依靠信息完整度、商品供给、评价/服务质量和需求匹配；广告流量依靠目标用户、预算、时段、创意、出价和关键词。曝光不是经营结果，必须追到点击、咨询/下单、核销和成本。
- **引流—促销—利润组品**：低门槛引流款获取首次交易，主推款表达核心价值，利润款或组合服务改善客单与毛利；每款都要匹配成本和承接能力。
- **用户期待管理**：门店定位、页面承诺、价格、线下服务和售后必须一致。评价管理从消费前开始，贯穿消费中和消费后。
- **单变量复盘**：一次测试只优先改变一个关键变量，记录周期、口径、预算、素材、时段、关键词和结果。

## 范围与限制

本 skill 是基于用户提供资料的结构化方法库，不替代美团当前规则、后台提示、合同、行业细则或法律意见。课件中的分值、时段、预算比例、尺寸、入口和效果描述，都必须按当前行业后台和真实数据核实后再执行。
