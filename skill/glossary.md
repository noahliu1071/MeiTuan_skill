# 术语表

- **D7/D30持续使用**：按开通同龄批次观察商户在第7/30天附近是否仍有真实经营交易；定义和窗口需先统一。
- **结算底价/交易费差**：合作商结算费率与商家实际费率之间可能形成的差额；不等于最终净利润。
- **经营参谋**：查看门店访问、转化、交易、评价等经营数据的工具或模块；入口和指标可能变化。
- **经营评分**：描述门店基础信息、商品、服务和交易任务的综合体系；权重和门槛按行业后台核验。
- **经营能力/平台营销能力**：资料中对支付后评价、收藏、部分餐饮销量同步等能力的统称；是否开通和适用须逐店确认。
- **开通、激活、持续使用**：分别指资质/产品开通、完成首笔或政策定义动作、观察期内继续真实经营；三者不能混用。
- **码牌/音箱**：轻量收款设备；音箱通常增加语音播报，具体网络、流量和保修按型号确认。
- **买单销量**：特定场景下线下买单数据同步形成的展示口径，不等于外卖或团购销量。
- **美团赚赚**：以商户收款、设备、交易管理及适用经营能力为核心的产品/业务体系；不能与历史点餐产品混同。
- **钱袋宝/美团支付相关通道**：资料中出现的美团支付通道口径；应与乐刷等第三方通道分开核验。
- **乐刷通道**：第三方收单通道，不等于美团自营通道；进件、结算和设备条件单独确认。
- **平台应计、到账、净留存**：平台计算的收入、实际收到的钱、扣除代理及成本后公司留下的钱；必须分开记账。
- **推广通**：资料中用于获取广告曝光的推广产品；计费、入口和能力以当前后台为准。
- **合格商机**：需求、主体和下一步沟通条件基本明确的线索；不是所有电话、评论或私信。
- **收款单**：创建并分享结构化收款请求的产品能力，涉及订单、付款和退款，不等于静态收款码。
- **扫码点餐**：餐饮桌台点餐和订单交付产品线，不是普通收款设备的默认功能。
- **首笔真实交易**：商户实际经营产生并可核验的第一笔交易，不包括为完成考核制造的交易。
- **支付后评价/收藏**：符合条件时消费者可能看到并主动操作的入口；不等于自动评价、必然展示或提升排名。
- **通道切换**：商户在不同支付通道间变更实际收款路径；生效时间、设备和认证须按当前后台确认。
- **用户期待管理**：让定位、页面承诺、价格、线下服务和售后与实际体验一致。
- **有效交易额**：按平台或合同定义剔除退款、异常等后的交易基数；计算前必须确认口径。
- **增长飞轮**：页面/产品、流量、真实履约、评价复购和数据复盘相互促进的闭环。
- **准入**：行业、地区、主体、资质和风控共同决定的入网条件；“全国推广”不等于全行业无条件开通。
- **自然流量**：不直接依赖广告出价获得的曝光与访问。
