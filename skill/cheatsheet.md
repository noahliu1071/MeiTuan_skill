# 运营速查表

## 先问客户的最少信息

行业/主营、城市与商圈、门店定位、目标客群、服务与成本、客单价、当前店铺页面、团购/套餐、近30天曝光/访问/咨询/下单/核销/评价数据、目标、预算、人手和时间。

## 页面检查

| 项目 | 检查 |
|---|---|
| 基础信息 | 名称、品类、电话、地址、商圈、营业状态真实完整 |
| 入口图 | 缩略图可辨、品牌/名称主体突出、素材有授权 |
| 头图 | 定位清晰、真实高清、不过亮不过暗、活动结束及时更新 |
| 相册/视频 | 环境、设施、项目、流程/效果与实际一致 |
| 页面承接 | 用户能理解服务、价格、限制和预约方式 |

## 团购检查

| 层级 | 作用 | 关键问题 |
|---|---|---|
| 引流款 | 降低首次尝试门槛 | 成本、限制、核销承接是否可控 |
| 主推款 | 表达核心价值 | 用户为什么选它，详情是否讲清 |
| 利润款 | 提升客单/毛利 | 组合是否真实有价值，是否容易加价争议 |

## 漏斗判断

- 曝光低：看基础信息、商品供给、搜索匹配、评分待办和投放覆盖。
- 点击低：看入口图、头图、价格、标题、首屏卖点和评价信任。
- 咨询/下单低：看套餐结构、详情、限制、价格、响应速度和承诺一致性。
- 核销/复购低：看履约、服务质量、售后、评价和商品实际价值。
- 投放花费高但结果弱：按曝光、点击、咨询/下单、核销逐层定位。

## 输出格式

每条建议写成：问题 → 证据 → 判断 → 动作 → 负责人/时间 → 成功指标 → 风险与待核验。
